# SlimRuimte — Stage 5: UX Flows, Screen States & Copy
Date: 2026-07-29 | Stage: 5 | Version: 1.0
Rule: Every screen has 4 states (empty / loading / error / success). No lorem ipsum. Activation in ≤3 steps.

---

## ACTIVATION PATH (≤3 steps from homepage to first value)

Step 1: Homepage → click "Scan mijn ruimte" (NL) / "Scan my room" (EN) / "Scanner ma pièce" (FR)
Step 2: Scan flow → complete LiDAR scan OR manual measurement → floor plan appears
Step 3: Style brief → answer 5 questions → 3 renders generated → ACTIVATION

## SCREEN 2 — ONBOARDING / DEVICE DETECT

URL: /start

Triggered immediately after "Gratis starten" click. No login required yet.

### Logic
```
detect iOS + iPhone 12 Pro or newer?
    YES → show LiDAR path (Screen 3a)
    NO  → show manual measurement path (Screen 3b)
```

### Copy
```
Welk apparaat gebruik je?

[📱 iPhone 12 Pro of nieuwer]     [📐 Ander apparaat]
  LiDAR — automatisch scannen       Handmaten invoeren
  Nauwkeurigheid: ±1-2 cm           Nauwkeurigheid: ±1-2 cm met laser

Met een meetlint of Bluetooth-laserafstandsmeter
(zoals een Bosch PLR) haal je dezelfde nauwkeurigheid.

### 4 States
- Empty: device type not yet selected — both cards shown, neither highlighted
- Loading: detecting device (instant, no spinner needed)
- Error: detection failed → show both options, user picks manually
- Success: correct option pre-highlighted based on detection

```

✓ Ronde af op 1 cm (bijv. 3,42 m → 3,42)
✓ Tik op "?" voor een video-instructie

Door/window detection (after walls):
```

```
